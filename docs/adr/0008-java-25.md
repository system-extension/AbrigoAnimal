# 0008 · Java 25 (LTS)

**Status:** aceita (2026-09-27) · migrada do Notion em 2026-11-07

## Contexto
O projeto foi iniciado com Java 21, mas o JDK instalado para rodar o projeto era o 25.
Os dois são LTS e o Spring Boot 4.1 suporta ambos.

## Decisão
**Java 25** em todo lugar: `pom.xml`, CI (`setup-java`) e `Dockerfile` (`eclipse-temurin:25`).
Versões não-LTS (26, 27) ficam de fora: suporte curto para um sistema que a ONG vai manter por anos.

## Consequências
- Todos da equipe precisam do JDK 25 instalado (`JAVA_HOME` apontando para ele)
- Próxima troca planejada só na próxima LTS
